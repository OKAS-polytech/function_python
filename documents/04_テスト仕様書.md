# CUIオセロアプリケーション テスト仕様書

## 1. 概要

本ドキュメントは、CUIオセロアプリケーションの品質を保証するためのテスト仕様を定義する。
テストは、内部設計書で定義された各純粋関数に対して、ユニットテストとして実装する。

## 2. テストフレームワーク

- `pytest` を使用する。

## 3. テスト対象とテストケース (v2.0)

テストは `tests/test_use_cases.py` に実装する。

### 3.1. `create_initial_state()`

| テストケースID | テスト内容 | 入力 | 期待される出力 (`GameState` の一部) |
| :--- | :--- | :--- | :--- |
| **IS-001** | 初期状態が正しく生成されるか | (なし) | `current_player` が `"Black"` であること |
| **IS-002** | 初期盤面の石の配置が正しいか | (なし) | `board[3][3]` と `board[4][4]` が `"White"` であること |
| **IS-003** | | | `board[3][4]` と `board[4][3]` が `"Black"` であること |
| **IS-004** | | | 上記以外のマスがすべて `None` (空) であること |
| **IS-005** | | | `game_over` が `False` であること |

### 3.2. `is_valid_move()`

| テストケースID | テスト内容 | 入力 (`board`, `player`, `position`) | 期待される出力 (`bool`) |
| :--- | :--- | :--- | :--- |
| **VM-001** | 正常な手（黒、1手目） | (初期盤面, `"Black"`, (2, 4)) | `True` |
| **VM-002** | 正常な手（白、2手目） | (VM-001後の盤面, `"White"`, (2, 3)) | `True` |
| **VM-003** | **異常系**: すでに石が置かれている | (初期盤面, `"Black"`, (3, 3)) | `False` |
| **VM-004** | **異常系**: 相手の石を挟めない場所 | (初期盤面, `"Black"`, (0, 0)) | `False` |
| **VM-005** | **異常系**: 盤面の範囲外 | (初期盤面, `"Black"`, (8, 8)) | `False` (※これは`handle_move`の入力チェックで対応) |

### 3.3. `_find_flippable_stones()`

| テストケースID | テスト内容 | 入力 (`board`, `player`, `position`) | 期待される出力 (`list[Tuple[int, int]]`) |
| :--- | :--- | :--- | :--- |
| **FS-001** | 右方向に1つ裏返せる | (初期盤面, `"Black"`, (2, 4)) | `[(3, 4)]` |
| **FS-002** | 左方向に2つ裏返せる | (特殊な盤面, `"White"`, (5, 5)) | `[(4, 5), (3, 5)]` |
| **FS-003** | 斜め方向に裏返せる | (特殊な盤面, `"Black"`, (5, 2)) | `[(4, 3)]` |
| **FS-004** | **異常系**: 裏返せる石がない | (初期盤面, `"Black"`, (0, 0)) | `[]` (空リスト) |
| **FS-005** | 複数の方向で裏返せる | (特殊な盤面, `"White"`, (x, y)) | `[(x1, y1), (x2, y2), ...]` |

### 3.4. `handle_move()`

| テストケースID | テスト内容 | 入力 (`state`, `position`) | 期待される出力 (`GameState` の一部) |
| :--- | :--- | :--- | :--- |
| **HM-001** | 正常な手を処理できるか | (初期`GameState`, (2, 4)) | - `board[3][4]` が `"Black"` に変わっていること<br>- `current_player` が `"White"` に変わっていること |
| **HM-002** | **異常系**: 無効な手を処理しようとした場合 | (初期`GameState`, (0, 0)) | - `board` が変化していないこと<br>- `current_player` が `"Black"` のままであること<br>- `message` にエラーメッセージが設定されていること |

### 3.5. `check_game_over()`

| テストケースID | テスト内容 | 入力 (`state`) | 期待される出力 (`GameState` の一部) |
| :--- | :--- | :--- | :--- |
| **GO-001** | ゲームが継続している状態（パスなし） | (両者とも手がある状態) | `game_over` が `False` |
| **GO-002** | どちらか一方がパスする状態 | (片方だけ手がない状態) | - `game_over` が `False`<br>- `current_player` が変化していないこと |
| **GO-003** | 両者とも手がなくゲーム終了（黒の勝ち） | (両者とも手がある状態) | - `game_over` が `True`<br>- `winner` が `"Black"` |
| **GO-004** | 両者とも手がなくゲーム終了（白の勝ち） | (両者とも手がある状態) | - `game_over` が `True`<br>- `winner` が `"White"` |
| **GO-005** | 引き分け | (両者とも手がない状態、同数) | - `game_over` が `True`<br>- `winner` が `None` |

### 3.6. `get_valid_moves()` (v2.0で追加)

| テストケースID | テスト内容 | 入力 (`state`) | 期待される出力 (`list[Tuple[int, int]]`) |
| :--- | :--- | :--- | :--- |
| **GM-001** | 初期盤面での黒の有効な手 | (初期`GameState`) | `[(2, 3), (3, 2), (4, 5), (5, 4)]` (順不同) |
| **GM-002** | 有効な手がない状態 | (手がない特殊盤面) | `[]` (空リスト) |

### 3.7. `find_best_move()` (v2.0で追加)

| テストケースID | テスト内容 | 入力 (`state`) | 期待される出力 (`Optional[Tuple[int, int]]`) |
| :--- | :--- | :--- | :--- |
| **BM-001** | 最も多くの石を裏返せる手を正しく選択できるか | (複数の手が存在し、裏返せる数が異なる盤面) | 最も裏返せる数が多い手の座標 |
| **BM-002** | 有効な手がない場合に`None`を返すか | (手がない特殊盤面) | `None` |
